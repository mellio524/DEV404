# DEV 404

Official DEV 404 site: music, videos, albums, artist story, and a trippy tech-thriller visual world.

## Render Static Site Setup

- Root Directory: `Frontend`
- Build Command: `npm run build`
- Publish Directory: `dist`
- Branch: `main`

## Local Preview

```bash
cd Frontend
npm install
npm run dev
```

## Production Build

```bash
cd Frontend
npm run build
```

The build creates static pages and assets in `Frontend/dist` for Render to publish.
